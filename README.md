# 💱 Convertix

Modern Telegram bot for converting 40+ world currencies using official exchange rates from the National Bank of Ukraine.

---

## ✨ Features

- Convert 40+ world currencies
- Official exchange rates from the National Bank of Ukraine
- Clean and user-friendly Telegram interface
- Currency search by code or name
- Paginated currency selection
- Fast and accurate conversion

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/MrGalacticas/convertix.git
```

Go to the project folder:

```bash
cd convertix
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Create a `.env` file:

```env
BOT_TOKEN=YOUR_BOT_TOKEN
```

Run the bot:

```bash
python bot.py
```
